# 互动魔杖实验室 · Interactive Wand Lab

一个浏览器端的手势识别原型，用普通摄像头识别亮绿色笔帽，也支持用鼠标或触屏画出相同轨迹。原型包含折线、闪电、顺时针圆环三个手势。摄像头画面在当前页面处理，不上传、不保存。

## 本地运行

需要 Python 3 和现代浏览器，无需安装第三方库。在项目根目录执行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

打开 <http://localhost:8000>。如端口被占用，换为 8001 并使用对应地址。不要双击 HTML，因为浏览器可能阻止从文件协议加载 JavaScript 模块。

### 鼠标或触屏

1. 找到右侧图谱，金点是起笔位置。
2. 在画布按住并拖动。从左向右，再向下画折线。画一条长于 45 个画布像素、包含至少六个采样点的轨迹。
3. 松开后应出现“已施法 · 折线”和约 1.5 秒的粒子反馈。只画一条直线，或直接点击，检查拒识提示。
4. 闪电的顺序为左上、右上、左下、右下。圆环从顶端起笔，顺时针闭合。

### 摄像头

1. 点击“启用摄像头”，在浏览器允许访问。准备亮绿色笔帽或在笔端贴绿色纸，背景避免绿色，面向均匀光源。
2. 将标记伸入画面，直到标记外侧出现浅绿色圈。依据镜像预览调整动作。
3. 点击“开始采集”或按空格，按图示挥动，完成后再次点击或按空格。采集窗口最长 6 秒，连续失去标记超过约 220 ms 会取消。若标记未被识别，可增大标记、改善照明、移走绿色背景物体。
4. 点击“切回鼠标”可停止摄像头。摄像头权限被拒绝时仍可使用鼠标。

## 复现实验

用 Node.js 18 或更高版本运行：

```bash
node evaluate.mjs results.json
```

固定种子 20261105 生成 200 条合成轨迹。每个目标手势 50 条，另外五种非目标轨迹各 10 条。对轨迹加入平移、等比缩放、±10° 旋转、坐标抖动和折线不等密度采样。输出行是期望类别，列是程序预测类别。脚本同时断言三个模板自匹配、零长度拒识、颜色连通域定位及无标记、冲突、过小和过大区域拒绝。

该实验覆盖分类逻辑与合成图像单元检查。真实摄像头的成功率、端到端延迟和多人环境表现需要另行采集。

## 文件

- `index.html`、`style.css`：界面和样式。
- `app.mjs`：输入适配、采集、状态提示与特效。
- `core.mjs`：颜色连通域、轨迹重采样和模板分类。
- `evaluate.mjs`、`results.json`：可重跑的实验和结果。
